# Сомонаи маҷаллаи илмӣ

Сомона барои маҷаллаи илмӣ бо панели идоракунии содда: шумораҳо, мақолаҳо бо аннотатсия ва PDF, бойгонӣ, ҷустуҷӯ, хабарҳо, саҳифаҳо ва қабули мақолаҳо аз муаллифон.

**Технология:** PHP 8.1+ ва MySQL 5.7+ / MariaDB 10.3+. Фреймворк, Composer ва сохтан (build) лозим нест. Дар ҳар хостинги оддӣ (cPanel, ISPmanager), Open Server, XAMPP ё VPS кор мекунад.

## Имкониятҳо

**Сомона барои хонандагон (бо се забон: тоҷикӣ, русӣ, англисӣ)**
- **Тарҳи муосир:** саҳифаи асосӣ бо муқоваи шумораи ҷорӣ, маҷалла бо рақамҳо, мақолаҳои бештар хондашуда, рубрикаҳо, хабарҳо, индексатсия
- **Ҳолати торик** (худкор аз рӯи танзими дастгоҳ ё бо тугма), **версия барои камбинон** (андозаи ҳарф ва контрасти баланд), мутобиқ ба телефон, чоп
- Бойгонӣ аз рӯи солҳо, шумора бо мундариҷа аз рӯи рубрикаҳо, «нонрезаҳо» (breadcrumbs)
- **Мақола:** муаллифон бо ҷои корашон, аннотатсия, калидвожаҳо, адабиёт, УДК, DOI, **хондани PDF дар худи сомона**, иқтибоси тайёр (ГОСТ) бо тугмаи нусха, **содирот ба BibTeX ва RIS** (Zotero, Mendeley, EndNote), мубодила (Telegram, WhatsApp, Facebook), мақолаи қаблӣ/навбатӣ, **мақолаҳои монанд**, шумораи дидану боргирӣ
- **Муаллифон:** рӯйхати алифбоӣ ва саҳифаи ҳар муаллиф (мақолаҳо, ҷои кор, ҳаммуаллифон, омор)
- **Рубрикаҳо:** саҳифаи алоҳида барои ҳар рубрика
- **Ҷустуҷӯ** ба ҳар се забон бо филтри сол ва рубрика, саҳифабандӣ ва ҷудо кардани калимаи ёфтшуда
- Эълон дар болои сомона, хабарҳо, саҳифаҳои матнӣ, **ирсоли мақола** аз ҷониби муаллифон

**Индексатсия ва SEO**
- **OAI-PMH 2.0** (`/oai.php`) — протоколе, ки базаҳои илмӣ (eLibrary/РИНЦ, CyberLeninka, BASE ва ғ.) метамаълумотро аз он мегиранд
- Мета-тегҳои **Google Scholar** (`citation_*`), JSON-LD (`ScholarlyArticle`, `Periodical`), Open Graph
- **RSS** барои мақолаҳо ва хабарҳо, `sitemap.xml` (бо муаллифон ва рубрикаҳо), `robots.txt`

**Панели идоракунӣ** (`/admin/`, бо забонҳои тоҷикӣ ва русӣ, бо ҳолати торик)
- **Шарҳи умумӣ:** графики хонандагон дар 30 рӯз, мақолаҳои бештар хондашуда, мақолаҳои нави воридшуда, **рӯйхати омодагии сомона** (чӣ ҳанӯз пур нашудааст), амалҳои охирин
- **Шумораҳо:** муқова, PDF-и пурра, **тартиб додани мақолаҳо** дар мундариҷа, пешнамоиши сиёҳнавис
- **Мақолаҳо:** ҳамаи майдонҳо ба се забон дар ҷадвалчаҳо (нуқтаи сабз нишон медиҳад, ки забон пур шудааст), PDF, «Нигоҳ доштан ва мақолаи навбатӣ», **пешнамоиш** пеш аз нашр
- **Муҳаррири визуалии матн** бо сарлавҳаҳо, рӯйхатҳо, иқтибос, пайвандҳо ва **бор кардани сурат**
- **Мақолаҳои воридшуда:** ҳолат (нав / дар тақриз / қабулшуда / радшуда), **қайдҳои таҳририя**, боргирии файл, ҷавоб бо почта
- **Танзимот:** ном, тавсиф, муассис, ISSN, тамос, логотип, ранги сомона, эълон, рӯйхати индексатсия, Telegram
- **Корбарон** бо нақшҳо (администратор / муҳаррир), **таърихи амалҳо** (кӣ, кай, чӣ тағйир дод)
- **Нусхаи эҳтиётӣ бо як тугма:** пойгоҳ (.sql) ва файлҳо (.zip)
- Огоҳӣ ҳангоми тарк кардани саҳифа бо тағйироти нигоҳ дошта нашуда

**Амният:** паролҳо танҳо бо хеш, PDO бо дархостҳои омодашуда, экранкунии ҳама матнҳо, CSRF дар ҳамаи формаҳо, маҳдудияти кӯшишҳои даромад ва ирсол, тозакунии HTML-и муҳаррир (`<script>`, `onclick`, `javascript:` нест карда мешаванд), навъи файл аз рӯи мундариҷа санҷида мешавад, папкаҳои `includes/` ва `storage/` аз браузер баста ҳастанд, дар `uploads/` код иҷро намешавад.

**Навсозӣ:** файлҳои навро болои кӯҳна бор кунед — сохтори пойгоҳ худкор нав мешавад (`includes/migrate.php`). Папкаҳои `uploads/`, `storage/` ва файли `includes/config.php`-ро иваз накунед.

## Насб дар хостинг

1. Дар панели хостинг **пойгоҳи холии MySQL** ва корбари онро созед.
2. Ҳамаи файлҳоро ба папкаи сомона (`public_html` ё папкаи поддомен) бор кунед.
3. Дар браузер `https://сомонаи-шумо/install.php`-ро кушоед. Маълумоти пойгоҳ, суроғаи сомона, логин ва пароли администраторро нависед ва «Насб кардан»-ро пахш кунед. Ҷадвалҳо ва маълумоти намунавӣ худкор сохта мешаванд.
4. Файли `install.php`-ро аз сервер нест кунед (пас аз насб он баста мешавад, вале нест кардан бехатартар аст).
5. Ба `/admin/` дароед. Дар **Шарҳи умумӣ** рӯйхати «Омодагии сомона» нишон медиҳад, ки чӣ бояд пур шавад. Дар **Танзимот** ном, логотип ва рангро иваз кунед. Маълумоти намунавиро иваз ё нест кунед.
6. Барои индексатсия суроғаи `https://сомонаи-шумо/oai.php`-ро дар базаҳои илмӣ сабт кунед ва сомонаро ба Google Search Console илова кунед (sitemap: `/sitemap.xml`).

Агар насбкунанда файли `includes/config.php`-ро навишта натавонад, матни онро нишон медиҳад — онро дастӣ созед.

**Маҳдудияти бор кардан:** барои PDF-ҳои калон дар танзимоти PHP `upload_max_filesize = 50M` ва `post_max_size = 64M` гузоред.

### Аввал дар поддомен, баъд дар домени асосӣ
1. Дар хостинг поддомен созед (масалан `demo.example.tj`) ва сомонаро дар он насб кунед.
2. Вақте ки тайёр шуд, файлҳоро (бо папкаҳои `uploads/` ва `storage/`) ба папкаи домени асосӣ нусха кунед.
3. Дар `includes/config.php` танҳо `site_url`-ро иваз кунед. Пойгоҳ ҳамон мемонад.

## Кор дар компютер (Open Server / XAMPP)

1. Папкаи лоиҳаро ба `OSPanel/domains/journal.local` (Open Server 5), `OSPanel/home/journal.local` (Open Server 6) ё `xampp/htdocs/journal` гузоред.
2. Дар phpMyAdmin пойгоҳи холӣ `journal` созед (`utf8mb4_unicode_ci`).
3. `http://journal.local/install.php` (ё `http://localhost/journal/install.php`)-ро кушоед. Корбари пойгоҳ одатан `root` бе парол аст. Дар Open Server 6 ба ҷои `localhost` номи модули MySQL-ро нависед (масалан `MySQL-8.0`).

**Docker:** `docker compose up -d --build`, сипас `http://localhost:8080/install.php`.

## nginx (ба ҷои `.htaccess`)

```nginx
root /var/www/journal;
index index.php;
client_max_body_size 64m;
location = /sitemap.xml { rewrite ^ /sitemap.php last; }
location = /robots.txt  { rewrite ^ /robots.php last; }
location ~ ^/(includes|storage|\.git)/ { deny all; }
location ~ \.(sql|md|yml)$ { deny all; }
location ~ ^/uploads/.*\.php$ { deny all; }
location ~ \.php$ {
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    fastcgi_pass unix:/run/php/php8.3-fpm.sock;
}
```

## Нусхаи эҳтиётӣ

Дар панел: **Система → Нусхаи эҳтиётӣ** — пойгоҳ (.sql) ва файлҳо (.zip) бо як тугма. Барқарор кардан: файли .sql-ро дар phpMyAdmin ворид кунед ва папкаҳои `uploads/` ва `storage/`-ро ба сервер баргардонед.

## Сохтор

```
index.php, archive.php, issue.php,      саҳифаҳои сомона
article.php, search.php, page.php,
news.php, submit.php, authors.php,
author.php, section.php
download.php                            боргирии PDF-и мақола (бо ҳисобкунак)
cite.php                                содироти иқтибос (BibTeX, RIS)
feed.php, oai.php                       RSS ва OAI-PMH
lang.php, sitemap.php, robots.php       забон, /sitemap.xml, /robots.txt
install.php                             насбкунанда
admin/                                  панели идоракунӣ
assets/                                 CSS ва JavaScript (бе китобхонаҳои берунӣ)
uploads/                                муқоваҳо, суратҳо, PDF
storage/submissions/                    файлҳои мақолаҳои воридшуда (аз браузер баста)
includes/                               код (аз браузер баста):
  bootstrap.php                           дар аввали ҳар саҳифа
  migrate.php                             навсозии худкори сохтори пойгоҳ
  config.php                              пайваст ба пойгоҳ (install.php месозад)
  db.php, queries.php                     пойгоҳ ва дархостҳо
  auth.php                                даромад ва нақшҳо
  html.php                                тозакунии HTML-и муҳаррир
  uploads.php                             бор кардани файлҳо
  layout.php, admin_layout.php            қолабҳо
  i18n.php, lang/site.php, lang/admin.php тарҷумаҳо
database.sql                            ҷадвалҳо ва маълумоти намунавӣ
```

Барои иваз кардани матнҳои интерфейс `includes/lang/site.php`-ро таҳрир кунед (калидҳо дар ҳар се забон бояд як хел бошанд).
