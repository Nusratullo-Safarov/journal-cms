# Сомонаи маҷаллаи илмӣ

Сомона барои маҷаллаи илмӣ бо панели идоракунии содда: шумораҳо, мақолаҳо бо аннотатсия ва PDF, бойгонӣ, ҷустуҷӯ, хабарҳо, саҳифаҳо ва қабули мақолаҳо аз муаллифон.

**Технология:** PHP 8.1+ ва MySQL 5.7+ / MariaDB 10.3+. Фреймворк, Composer ва сохтан (build) лозим нест. Дар ҳар хостинги оддӣ (cPanel, ISPmanager), Open Server, XAMPP ё VPS кор мекунад.

## Имкониятҳо

**Сомона (бо се забон: тоҷикӣ, русӣ, англисӣ)**
- Саҳифаи асосӣ: номи маҷалла, шумораи охирин бо мундариҷа, хабарҳо, маълумот (муассис, ISSN, даврият)
- Бойгонӣ аз рӯи солҳо бо муқоваҳо
- Шумора: муқова, PDF-и пурра, мундариҷа аз рӯи рубрикаҳо
- Мақола: муаллифон ва ҷои корашон, аннотатсия, калидвожаҳо, адабиёт, УДК, DOI, саҳифаҳо, PDF, «Чӣ тавр иқтибос овардан» (ГОСТ), шумораи дидану боргириҳо. Ном ва аннотатсия ба забонҳои дигар дар поён нишон дода мешаванд
- **Google Scholar:** ҳар мақола мета-тегҳои `citation_*` дорад, то дар Google Scholar пайдо шавад
- Ҷустуҷӯ аз рӯи ном, муаллиф, аннотатсия ва калидвожаҳо ба ҳар се забон
- Саҳифаҳо: «Дар бораи маҷалла», «Ҳайати таҳририя», «Талабот ба муаллифон», «Одоби нашр» ва ҳар саҳифаи дигар
- Хабарҳо ва эълонҳо
- **Ирсоли мақола:** муаллиф файли DOC/DOCX/PDF мефиристад, дар панел пайдо мешавад (ихтиёрӣ — огоҳӣ дар Telegram)
- SEO: `sitemap.xml`, `robots.txt`, canonical, Open Graph. Мобилӣ ва тез

**Панели идоракунӣ** (`/admin/`, бо забонҳои тоҷикӣ ва русӣ)
- Шумораҳо: сол, ҷилд, рақам, сана, муқова, PDF-и пурра, нашр ё сиёҳнавис
- Мақолаҳо: ҳамаи майдонҳо ба се забон дар ҷадвалчаҳо, PDF, тугмаи «Нигоҳ доштан ва мақолаи навбатӣ» барои пур кардани шумора
- Рубрикаҳо, саҳифаҳо (бо муҳаррири визуалии матн), хабарҳо бо сурат
- Мақолаҳои воридшуда: рӯйхат, боргирии файл, ҳолат (нав / дар тақриз / қабулшуда / радшуда), ҷавоб бо почта
- **Танзимот:** номи маҷалла ва тавсиф ба се забон, муассис, ISSN, тамос, логотип, ранги асосии сомона, Telegram
- **Корбарон:** администратор ва муҳаррир (муҳаррир ба танзимот ва корбарон дастрасӣ надорад)

**Амният:** паролҳо танҳо бо хеш, PDO бо дархостҳои омодашуда, экранкунии ҳама матнҳо, CSRF дар ҳамаи формаҳо, маҳдудияти кӯшишҳои даромад, тозакунии HTML-и муҳаррир (`<script>`, `onclick`, `javascript:` нест карда мешаванд), навъи файл аз рӯи мундариҷа санҷида мешавад, папкаҳои `includes/` ва `storage/` аз браузер баста ҳастанд, дар `uploads/` код иҷро намешавад.

## Насб дар хостинг

1. Дар панели хостинг **пойгоҳи холии MySQL** ва корбари онро созед.
2. Ҳамаи файлҳоро ба папкаи сомона (`public_html` ё папкаи поддомен) бор кунед.
3. Дар браузер `https://сомонаи-шумо/install.php`-ро кушоед. Маълумоти пойгоҳ, суроғаи сомона, логин ва пароли администраторро нависед ва «Насб кардан»-ро пахш кунед. Ҷадвалҳо ва маълумоти намунавӣ худкор сохта мешаванд.
4. Файли `install.php`-ро аз сервер нест кунед (пас аз насб он баста мешавад, вале нест кардан бехатартар аст).
5. Ба `/admin/` дароед → **Танзимот**: ном, логотип ва рангро иваз кунед. Маълумоти намунавиро (шумораҳо, мақолаҳо) иваз ё нест кунед.

Агар насбкунанда файли `includes/config.php`-ро навишта натавонад, матни онро нишон медиҳад — онро дастӣ созед.

**Маҳдудияти бор кардан:** барои PDF-ҳои калон дар танзимоти PHP `upload_max_filesize = 50M` ва `post_max_size = 64M` гузоред.

### Аввал дар поддомен, баъд дар домени асосӣ
1. Дар хостинг поддомен созед (масалан `demo.example.tj`) ва сомонаро дар он насб кунед.
2. Вақте ки тайёр шуд, файлҳоро (бо папкаҳои `uploads/` ва `storage/`) ба папкаи домени асосӣ нусха кунед.
3. Дар `includes/config.php` танҳо `site_url`-ро иваз кунед. Пойгоҳ ҳамон мемонад.

## Кор дар компютер (Open Server / XAMPP)

1. Папкаи лоиҳаро ба `OSPanel/domains/journal.local` (Open Server 5), `OSPanel/home/journal.local` (Open Server 6) ё `xampp/htdocs/journal` гузоред.
2. Дар phpMyAdmin пойгоҳи холӣ `journal` созед (`utf8mb4_unicode_ci`).
3. `http://journal.local/install.php` (ё `http://localhost/journal/install.php`)-ро кушоед. Корбари пойгоҳ одатан `root` бе парол аст. Дар Open Server 6 ба ҷои `localhost` номи модули MySQL-ро нависед (масалан `MySQL-8.0`).

**Docker:** `docker compose up -d --build`, сипас `http://localhost:8080/install.php`.

## nginx (ба ҷои `.htaccess`)

```nginx
root /var/www/journal;
index index.php;
client_max_body_size 64m;
location = /sitemap.xml { rewrite ^ /sitemap.php last; }
location = /robots.txt  { rewrite ^ /robots.php last; }
location ~ ^/(includes|storage|\.git)/ { deny all; }
location ~ \.(sql|md|yml)$ { deny all; }
location ~ ^/uploads/.*\.php$ { deny all; }
location ~ \.php$ {
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    fastcgi_pass unix:/run/php/php8.3-fpm.sock;
}
```

## Нусхаи эҳтиётӣ

Пойгоҳи додаҳо (экспорт дар phpMyAdmin ё `mysqldump`) ва папкаҳои `uploads/` (муқоваҳо, PDF) ва `storage/` (мақолаҳои воридшуда).

## Сохтор

```
index.php, archive.php, issue.php,      саҳифаҳои сомона
article.php, search.php, page.php,
news.php, submit.php
download.php                            боргирии PDF-и мақола (бо ҳисобкунак)
lang.php, sitemap.php, robots.php       забон, /sitemap.xml, /robots.txt
install.php                             насбкунанда
admin/                                  панели идоракунӣ
assets/                                 CSS ва JavaScript (бе китобхонаҳои берунӣ)
uploads/                                муқоваҳо, суратҳо, PDF
storage/submissions/                    файлҳои мақолаҳои воридшуда (аз браузер баста)
includes/                               код (аз браузер баста):
  bootstrap.php                           дар аввали ҳар саҳифа
  config.php                              пайваст ба пойгоҳ (install.php месозад)
  db.php, queries.php                     пойгоҳ ва дархостҳо
  auth.php                                даромад ва нақшҳо
  html.php                                тозакунии HTML-и муҳаррир
  uploads.php                             бор кардани файлҳо
  layout.php, admin_layout.php            қолабҳо
  i18n.php, lang/site.php, lang/admin.php тарҷумаҳо
database.sql                            ҷадвалҳо ва маълумоти намунавӣ
```

Барои иваз кардани матнҳои интерфейс `includes/lang/site.php`-ро таҳрир кунед (калидҳо дар ҳар се забон бояд як хел бошанд).
